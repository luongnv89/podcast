Bob: But can a judge be trusted every time?

Alice: Böckeler is careful here. LLMs can partially address problems like redundant tests, but expensively and probabilistically, not on every commit. Cheap, deterministic checks like tests and linters are fast enough to run on every change.

Bob: Any warning label on all these metrics?
